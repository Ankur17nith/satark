# Presenter narration for the demo video

Read these lines on camera while the demo video plays. Each line is timed to what is on screen; the time budget allows a calm pace (about 2 words per second).

## How to record

1. Play `docs/media/satark-demo.mp4` on a laptop with the **sound off**.
2. Record yourself on your phone (front camera, landscape or portrait both work), framed from the chest up, facing a window or a lamp. Use earphones with a mic if you have them.
3. Start recording, then start the video, and **clap once on screen exactly when the video starts**. The clap lets the clips be lined up exactly.
4. Read each line when its time comes. Don't worry about being exact: a second early or late is fine.
5. Record the whole 2:38 in one take. Send the file as it is.
